# 玩物 · 私人游戏平台

纯静态、无运行时第三方依赖的个人游戏大厅。当前接入切水果，后续游戏按模块独立加入。整个 `dist` 目录可直接部署到 Nginx，支持部署在域名根目录或子目录。

## 已有功能

- 游戏大厅、搜索、收藏、最近游玩、按游戏和模式统计的个人最佳。
- 切水果：西瓜、橙子、柠檬、猕猴桃、苹果、草莓、梨、桃子、菠萝、芒果、火龙果、蓝莓，共 12 种；60 秒挑战和不限时练习。
- 经典挑战结束后追加 10 秒「胜利果实」：反复划切金色果实，每刀 20 分起，每 5 刀提高 5 分、最高 50 分；结束后统一结算总分与奖励。暂停和切到后台会冻结倒计时。
- 鼠标、触摸、键盘操作，游戏内暂停、音效、全屏与返回大厅。
- iPad 横竖屏适配、添加到主屏幕、HTTPS 下的离线缓存。
- 自动继承旧版切水果的最高分和音效设置。

## 本地运行与部署

```sh
npm run build
npm run check
npm run dev
```

浏览器打开 http://localhost:4173/ 。开发服务器监听本机所有网络接口，同一局域网可使用电脑 IP 和 4173 端口访问。

`npm run build` 只根据现有静态文件更新离线资源清单，无需安装依赖。修改源码或新增游戏后运行一次，再把 **整个 dist 目录（保留这一层）** 上传到服务器 `/opt/games/`，确保首页位于 `/opt/games/dist/index.html`。如果整个项目放在 `/opt/games/`，首页也是这个位置；项目根目录本身没有 `index.html`，Nginx 的 `root` 应指向 `/opt/games/dist`。

独立域名部署使用 `deploy/nginx.conf`：将其中两个 `server` 块放入现有 Nginx 的 `http` 配置范围，访问 `https://games.xzxlove.cn/`，HTTP 自动以 308 跳转到 HTTPS。证书和私钥路径分别为 `/etc/nginx/ssl/xzxlove.cn.pem`、`/etc/nginx/ssl/xzxlove.cn.key`；证书需覆盖 `games.xzxlove.cn`。Nginx 的 `http` 块应保留标准 `mime.types` 配置。在服务器执行 `sudo nginx -t && sudo nginx -s reload` 生效，正式部署无需运行 `npm run dev`。

大厅与游戏均为真实 HTML 页面，无需单页应用路由回退或后端服务。直接访问 `/games/fruit-slice/index.html` 也能玩。

### 挂到已有项目的 `/game/` 路径

`4173` 仅用于 `npm run dev` 本地预览。正式部署时只上传 `dist` 中的全部内容，由现有 Nginx 提供静态文件，无需运行 Node 服务或增加业务端口。

1. 本地执行 `npm run build`，把整个 `dist` 目录上传到服务器 `/opt/games/`，确保首页位于 `/opt/games/dist/index.html`。
2. 将 `deploy/nginx-subpath.conf` 中的两个 `location` 加到已有网站的 `server` 块内，把 `alias` 改成服务器上的实际游戏目录，保留末尾 `/`。原项目继续使用自己的路由配置。
3. 在服务器执行 `sudo nginx -t && sudo nginx -s reload`，通过 `https://你的现有域名/game/` 访问；现有项目可以直接添加指向 `/game/` 的链接。

该配置使用 `alias` 将 URL 路径映射到静态目录，不需要 `proxy_pass`。`^~ /game/` 避免现有站点的通用静态资源正则接管游戏资源。缺失文件按静态文件规则处理，不需要回退到主项目首页。Nginx 的 `http` 块应保留标准 `mime.types` 配置，以正确提供 JavaScript、CSS 和音频。

游戏资源、页面链接和 PWA 配置均使用相对路径；游戏自己的 Service Worker 范围会落在 `/game/` 下。若现有项目在 `/` 注册了自己的 Service Worker，需要检查它的导航回退和缓存规则，避免拦截 `/game/`。如需更换入口前缀，同步修改配置中的两个 `location` 和重定向地址即可。

## 模块结构

```text
dist/
  index.html               游戏大厅
  platform.js / .css       大厅交互和样式
  games.js                 游戏目录：新增游戏的统一注册处
  shared/
    storage.js             本地收藏、记录、设置与旧数据迁移
    sdk.js                 游戏记录接口
    pwa.js                 统一离线注册
  games/
    fruit-slice/           切水果的 HTML、样式、逻辑、物理和素材
  assets/                  平台图标
  manifest.webmanifest     平台 PWA 配置
  sw.js / precache.js       离线资源缓存
```

## 加一个新游戏

1. 创建 `dist/games/<game-id>/index.html`，把游戏自己的 JS、CSS 和素材放在该目录中。
2. 在 `dist/games.js` 的 `games` 数组中增加条目：唯一 `id`、标题、描述、分类、标签、入口、封面、背景与模式。参考已有 `fruit-slice` 条目。链接全部使用相对路径，以兼容子目录部署。
3. 游戏页加上 `../../index.html` 返回大厅链接，并引用 `../../manifest.webmanifest`。
4. 接入下面的记录接口，让大厅自动展示最近游玩与个人最佳。
5. 运行 `npm run build` 和 `npm run check`，重新上传 `dist`。新增目录内的静态资源会自动进入离线清单。

```js
import { createGameSession, library } from '../../shared/sdk.js';
import { registerOffline } from '../../shared/pwa.js';

const session = createGameSession('your-game-id');
registerOffline();

// 真正开始一局时调用，不要在打开菜单时调用。
session.start('classic');

// 每局结束时调用。seconds 为实际游玩秒数，排除暂停。
session.finish({ mode: 'classic', score: 120, seconds: 60 });

const personalBest = session.best('classic');
const soundEnabled = library.read().settings.sound;
```

游戏渲染与规则由自己的模块负责，大厅不依赖具体游戏的 Canvas、DOM 或内部状态。模式 ID 应与目录中的 `modes` 一致，分数越高越好；同一局重复调用 `finish` 不会重复记录。

## 数据与离线说明

所有记录保存在当前浏览器，暂无跨设备同步。清理站点数据会清除记录，隐私模式或禁用存储时仍可玩，但只保留当前页面内的临时状态。`累计开局` 包括中途退出的局；最佳分数只在完成一局后保存。

HTTPS 或 localhost 环境支持 Service Worker；首次完整缓存后可离线游玩。更新在回到大厅时激活，不在一局游戏进行中主动替换资源。新增游戏后需要重新构建缓存清单。

iPad 用 Safari 分享菜单「添加到主屏幕」安装游戏室。大厅、切水果和亲子小游戏的全屏按钮在进入全屏后请求锁定横屏，退出全屏（包括 Esc 或浏览器退出）时解除方向锁定。浏览器不支持或拒绝方向锁定时，保留全屏，并在竖屏下提示横放设备、关闭系统竖屏锁定；不支持 Fullscreen API 时提示添加到主屏幕。系统状态栏和手势区域仍以设备系统为准。

## 亲子益智小游戏

新增 8 个独立入口，均可从大厅搜索、收藏和打开：

| 游戏 | 入口目录 | 玩法 |
| --- | --- | --- |
| 形状回家 | `shape-home` | 9 种形状分组登场，每关配对 2 或 3 种 |
| 听声音找动物 | `animal-sounds` | 8 种动物轮流登场，每关 3 道听音配对 |
| 颜色分一分 | `color-sort` | 6 种颜色更换组合，每关分 2 或 3 种颜色 |
| 两块小拼图 | `little-puzzle` | 汽车、小鸭、小熊等 8 幅图片，每关 2 或 4 块 |
| 小熊藏哪了 | `bear-hide` | 4 个场景轮换，下一关更换躲藏位置，盒子仍然固定 |
| 照顾小熊 | `bear-care` | 点心、野餐、故事等 5 个情境，使用 6 种生活物品 |
| 小花喝水 | `flower-water` | 每关种不同的花，6 种颜色与花形组合 |
| 动物音乐屋 | `animal-music` | 4 段旋律与不同动物朋友轮换，每关 8 或 12 次探索 |

适合大人陪同探索。没有倒计时、扣分或失败结算；每关完成后可点「下一关」更换内容，也可「再玩本关」或回大厅休息；每完成 5 关会温柔提示休息。配对与拼图同时支持拖动、点选以及键盘 Tab / Enter 操作。触摸拖放有位置容差。暂停、切到后台会停止声音和计时，回来后手动继续。

关卡持续编号，内容按主题组合轮换，物品位置随机排列；「轻松玩」保持 2 个选择，「多试一点」保持 3 个选择（拼图为 2 / 4 块），不会随关数自动增加难度。当前关卡与节奏按游戏保存在当前浏览器，下次可继续；本关中途离开会从本关开头重试。重玩已完成关卡不会让保存的关数倒退，存储被禁用时仍能在页面内连续玩。

页面和封面位于各自 `dist/games/<game-id>/` 目录，共用 `dist/shared/toddler/` 下的规则、SVG 插画、音频与交互代码，无新增第三方依赖。它们通过 `catalog.js` 注册到大厅，并自动加入离线清单。`recordKind: 'activity'` 的游戏在大厅显示探索数和完成轮数，不显示分数排行。

中文提示与动物拟声使用设备的语音合成，乐器由 Web Audio 生成。画面和游戏资源可离线缓存；中文语音是否可离线使用取决于设备上的中文声音。无语音支持时仍有文字、图片提示，家长可陪读。动效遵循系统减少动态效果设置。

验证：`npm run build`、`npm run check`；浏览器完成全部 8 个小游戏，检查配错重试、拖放、暂停恢复、四块拼图及 390×844 / 1024×768 布局。规则测试覆盖 8 个游戏各连续 30 关、两个难度、重复操作、错误顺序、内容覆盖、进度持久化及存储不可用时继续游玩。

## 宝宝启蒙乐园

大厅中的「宝宝启蒙乐园」是一个独立的八主题合集，入口为 `dist/games/tiny-wonderland/index.html`。通过本地服务器访问 `/games/tiny-wonderland/index.html`，或把更新后的全部 `dist` 内容部署到现有静态站点。

- **数字小火车**：逐个装苹果，数字与实际数量对应；默认 1～3，可在家长设置中扩展到 1～10。
- **动物农场**：6 个动物朋友，认识名称、模仿拟声、打招呼、喂点心和捉迷藏。
- **ABC 字母屋**：A～Z 全部 26 个字母，分别播放字母名和例词；字母选择栏可直接跳转。
- **颜色花园**：6 种颜色，浇水让花朵显出颜色。
- **形状积木**：6 种形状，点击积木归位，在「找一找」中辨认形状。
- **水果小厨房**：6 种水果，给小熊喂食，示范「我要苹果」。
- **交通小镇**：6 种交通工具，认识名称和动作。
- **生活小屋**：喝水、洗手、穿鞋、睡觉、你好、再见。

每个主题都支持「听一听」「找一找」「说一说」。可随时换内容，不要求发音正确才能继续；表达模式通过亲子确认继续，不调用麦克风。五个小发现后自然结束，也会在家长设置的 3 或 5 分钟**实际游玩时间**到达时提示休息；暂停、家长弹窗及后台时间不计入。设置有家长算术题入口，可选择中文/英文、2/3 个选项、声音和动画。偏好与去过的主题存在本地；大厅按亲子活动记录，不显示分数。

画面是本地 SVG，配音包含 420 条预生成的普通话/英语语音，约 5.8 MB。无需账号或第三方服务。HTTPS / localhost 首次缓存完成后可离线加载；缓存支持音频分段请求。音频文件不可用时才回退到设备语音合成，回退声音的语言、音色和离线支持由设备决定。这些配音为系统语音合成，并非真人录音。

维护代码：`content.js` 保存教学内容，`art.js` 绘制插画，`session.js` 管理互动和有效计时，`game.js` 管理页面。调整配音文字后可在 macOS 执行 `node scripts/generate-wonderland-audio.mjs` 重新生成音频（需要系统 Tingting / Samantha 声音及本地语音服务权限）；普通运行和部署不需要 macOS。

验证：`npm run check` 覆盖内容完整性、难度、配对、逐物计数、跳过/重复操作、整轮结束、暂停计时及全部音频资源；离线音频 Range 响应有独立测试。浏览器实测八主题的三种玩法、家长设置、中英切换、五次发现后的结束页，以及手机和平板响应式布局。

## 果园连连看

入口为 `dist/games/fruit-connect/index.html`，本地预览：`http://localhost:4173/games/fruit-connect/index.html`。已注册到游戏大厅，支持搜索、收藏、最近游玩和按模式保存个人最佳。

- 点击相同水果，用不穿过其他水果、最多两次转弯的路线消除；允许从棋盘外围连线。
- 三关分别为清晨果园（48 格）、午后微风（56 格）、落日野餐（64 格），逐步加入 12 种本地 SVG 水果。
- 经典闯关每关分别限时 180 / 170 / 160 秒；悠闲时光没有倒计时。每对 100 分，5 秒内连续消除可累积连击，额外奖励最高 100 分；经典过关剩余每秒加 10 分。
- 每关有 3 次提示和 3 次洗牌；初始棋盘与洗牌检查完整消除序列，过程中无可连的水果会自动免费洗牌。空位保留，洗牌不补回已消除的水果。
- 支持鼠标、触屏、方向键与 Enter / 空格；H 提示、R 洗牌、Esc 暂停。切到后台自动暂停，回来手动继续。更换模式或重新开始前会提示确认。
- 接入平台音效偏好、全屏和离线缓存；没有新增第三方依赖。游戏与规则分别位于 `game.js`、`model.js`，水果插画位于 `art.js`。
- 成功消除后用中文播报水果名称，沿用右上角声音开关。连续消除时播报最新水果，暂停、静音或切到后台时停止。播报使用设备语音合成，中文音色与离线可用性取决于设备上的中文声音。

验证：`npm run build`、`npm run check`。路径规则与独立搜索算法交叉检查，覆盖随机棋盘可完成性、洗牌保留空位、道具限制、暂停计时、连击、三关结算。浏览器实际完成全部三关，并检查提示、洗牌、暂停、手机 390×844 与平板 1024×768 布局及最高分保存。
